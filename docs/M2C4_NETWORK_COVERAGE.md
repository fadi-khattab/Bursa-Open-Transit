# BOT-M2C.4 — Full current-model coverage and scope-bound certification

Offline normalized synthetic contract. Covers ten record groups: agency, stop, route, pattern, service, trip (ordered visits), shape (ordered vertices), station, geometry (pattern anchors), transfer (directed pair). Each group must be explicit even when empty. Geometry identity is keyed by pattern; transfer identity is a synthetic digest of the ordered canonical pair. External record keys use the existing typed identity ledger. Nested values are verified as whole structured fields, including order and multiplicity; source references are already normalized canonical IDs, not a verified raw-source adapter.

Audit scans every record in every selected pinned snapshot independently of scope membership. Known typed identities produce inspectable observations even outside scope or when disagreeing with the model. Unknown identity, extra/missing record/group/field, model mismatch, and source omission fail relative coverage. Conflicts compare observed values by typed canonical identity and field without choosing the model as winner. Values use exact canonical JSON equality (including numeric representation); this deliberately conservative policy is not a tolerance policy. Malformed structured values cannot match a valid canonical record; no independent schema validation of mismatching observations is claimed.

Scope lists expected external-to-canonical mappings by source and kind. A separate reference artifact pins the scope digest, the exact selected namespace/digest set, and the ledger history digest. Changing any of them cannot satisfy the unchanged reference. The report binds model content and anchor policy as well. scoped_certificate means only relative completeness + reference match + no observed conflict, not a trusted certificate; no scenario exclusions or input reports are accepted. Missing/estimated timing is reported separately; null timing does not become known simply because represented faithfully. Optional collections may be empty under the declared inventory, not proof that none exist in reality.

Reference pins are supplied by callers; no institutional independence, source authenticity, completeness of the real network, raw reference reconciliation, cross-version alignment, persistent storage, verified derivation integration, or publication authority is established. In particular this layer cannot detect a wholly omitted source if the reference itself omits it. Legacy conflict and derivation APIs remain unchanged. No GTFS readiness decision or real data access.
