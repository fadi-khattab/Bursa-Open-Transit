# Roadmap and exit gates

| Milestone | Deliverable | Exit gate |
|---|---|---|
| M0.1 | Foundation | Local tests pass; no production release |
| M1 | Source discovery and institutional agreement | Documented source inventory and agency-approved access terms before real ingestion |
| M2 | Canonical data model | Referential integrity, stable IDs, service calendar and time semantics tested |
| M3 | GTFS Schedule | Deterministic synthetic export; required files and relationships validated |
| M4 | Independent validation | MobilityData validator plus semantic/negative tests and report |
| M5 | Pilot | Synthetic pilot; real pilot only with scoped permission and acceptance criteria |
| M6 | GTFS Realtime | Stable Schedule links, freshness and outage handling verified |
| M7 | Operations | Secure hosting, monitoring, rollback, maintenance and cost plan |
| M8 | Partner review | Authorized feed, agency endorsement, Google onboarding and private QA |
| M9 | Public launch | Agency permission, platform acceptance, operating owner and rollback readiness |

Institutional and synthetic engineering tracks can proceed in parallel. Real-data ingestion and external publication are separate authorization decisions. Realtime public integration depends on the accepted Schedule feed and applicable partner requirements.

M0.1 does not certify any transport data or grant publication authority.
